# TDS — Lançamentos

Este repositório contém apenas os lançamentos (versões) da app TDS
(Truck Driver Service), cada um com o respetivo ficheiro APK e notas de
versão. Não contém código-fonte — o código-fonte está num repositório
privado separado.

A app usa este repositório (através da API pública de "releases" do
GitHub) para verificar automaticamente se há uma versão mais recente
disponível.
